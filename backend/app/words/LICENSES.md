# Word lists

Generated by `backend/tools/build_words.py` (run it again to refresh them). They are only word lists, shipped so the server never needs the internet.

- `en_us.txt.gz`, `en_gb.txt.gz`: expanded from the SCOWL-derived Hunspell dictionaries `en` (American) and `en-GB` in [wooorm/dictionaries](https://github.com/wooorm/dictionaries). Licensed under the SCOWL / Hunspell English licences (a permissive BSD-like licence, see the `license` file in `dictionaries/en`; Copyright Kevin Atkinson and contributors).
- `tech.txt.gz`: terms from the language and tool dictionaries of [streetsidesoftware/cspell-dicts](https://github.com/streetsidesoftware/cspell-dicts) (MIT, plus the licences of each individual dictionary).
- `extra.txt`: words of our own. Add yours there, or point `KOKO_EXTRA_WORDS` at a text file with one word per line.
